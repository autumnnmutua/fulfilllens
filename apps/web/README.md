# FulfillLens CN Web

React、TypeScript 与 Vite 前端。当前已实现响应式导入向导、可筛选分析总览、透明诊断、订单事件下钻、What-if 方案模拟、教学案例、报告导出、本地数据清理和首次使用者指标解释。

开发服务器默认监听 `127.0.0.1:5173`，并将 `/api` 和 `/health` 代理到 `http://127.0.0.1:8000`。

在仓库根目录安装依赖后运行：

```powershell
npm run dev:web
```

环境变量见 `.env.example`。

访问 `/import` 可上传 CSV/XLSX、选择编码/工作表、查看脱敏预览、覆盖字段建议、处理未知状态并下载质量报告。浏览器不直接解析或长期保存文件，核心规则只在本机 API 执行。

访问 `/analytics` 可选择已确认的订单及可选事件数据集，按日期、仓库、承运商、地区、状态和异常类型统一筛选。页面展示数据上下文、7 个核心指标、日/周趋势、履约时长分布、节点平均/P50/P90、业务维度对比、服务端分页订单和安全 CSV；前端不实现核心指标公式。

访问 `/diagnostics` 可查看规则/阈值、严重度、帕累托、瓶颈节点、流程路径、维度下钻和受影响订单；订单抽屉分层展示事实、规则判断、谨慎可能原因、建议核查和标准事件时间线。前端不复制规则公式。

访问 `/scenarios` 会从已选择数据集自动建立只读基线，可创建、重命名、复制和删除方案，配置仓内、揽收、承运商结构和承诺策略，查看指标变化、订单调整证据和单参数敏感性表。前端不修改最终指标，所有结果显示为情景估算。

访问 `/reports` 可沿用最近一次分析总览筛选，选择十个报告章节和可选模拟方案，预览版本、覆盖率、分子/分母和分层诊断，再创建 Markdown、自包含 HTML 或五类 CSV 导出任务。页面常驻显示进度、失败和取消；订单标识默认掩码，开启时必须二次确认。

访问 `/settings` 可查看并不可逆删除本地数据集及关联上下文，也可查看 Workers AI 脱敏配置状态，并在勾选外部调用确认后执行固定合成探针。浏览器不接收或保存 Cloudflare Token。

发布、测试、隐私和贡献说明以根目录中文/英文 README、`SECURITY.md` 与 `CONTRIBUTING.md` 为准。

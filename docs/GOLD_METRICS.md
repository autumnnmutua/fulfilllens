## 汇总人工对照

| 指标           | 人工公式                                         |    期望值 |
| -------------- | ------------------------------------------------ | --------: |
| 订单总数       | 8 个唯一订单                                     |         8 |
| 有效订单数     | 8 / 8                                            |         8 |
| OT             | 4 个按时 / 5 个可计算；覆盖 5 / 6                |     80.0% |
| IF             | 5 个足量 / 6 个可计算                            |     83.3% |
| OTIF           | 3 个按时足量 / 5 个可计算                        |     60.0% |

| 退回率         | 1 / 8                                            |     12.5% |

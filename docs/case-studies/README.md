统一操作路径：启动项目 → 打开“教学案例” → 阅读替换提示 → 一键载入 → 分析总览 → 异常诊断 → 方案模拟。此前本地数据集不会被删除，但浏览器当前分析指针会切换到所选案例。

教师应要求学生同时报告指标值、分母、覆盖率、规则阈值和样本量，并把“事实”“规则判断”“可能原因”“建议核查”分开书写。

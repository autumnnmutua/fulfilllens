# ADR 0009：订单与事件层可复现情景模拟

- 状态：已接受
- 日期：2026-08-01
- 决策范围：阶段 7 What-if 模拟

## 背景

方案模拟需要比较仓内、揽收、承运商结构和承诺策略，但不能通过直接改写最终指标制造改善，也不能把历史关联包装成真实预测。原始标准数据必须保持只读，承运商结构调整又需要一种能复用现有无权重指标引擎的方法。

## 决策

1. 所有确定性改善在订单或事件深拷贝上实施，并重新调用 `metrics-v1.1.0`；
2. 变换执行顺序固定并版本化；
3. 承运商结构使用固定种子的历史联合分布经验重采样，使用最大余数法保持订单总数；
4. 模拟订单和事件使用新主键，同时保留来源订单 ID；
5. 方案元数据存入 SQLite，原始数据继续只存 DuckDB 标准层；
6. 响应返回输入/方案指纹、种子、调整明细、假设、警告和“情景估算”标识；
7. 核心模拟不调用 Workers AI。

## 结果

优点：指标口径单一、原始数据不变、结果可复现、订单可追溯、测试可人工复算。代价：经验重采样保留混杂结构，小样本可能重复订单；完整时间传导忽略容量与排队，结果只适合方向性比较。

## 被拒绝方案

- 直接为最终 OTIF/P90 增减固定值：不可追溯，违反指标单一来源；
- 在前端复制指标公式：容易与后端口径漂移；
- 让大模型生成方案数值：不可复现且无法验证；
- 首版引入离散事件仿真或优化求解器：缺少容量、成本和排班数据，复杂度超过 MVP。

# ADR-0003：本地优先运行模式

- 状态：Accepted
- 日期：2026-07-29
- 取代：无

## 背景

项目会处理订单、仓库和物流轨迹，可能包含可关联标识和个人信息。目标用户需要低成本教学和经营分析，不应被迫注册或把数据上传到云端。

## 决定

- Web、API、DuckDB、SQLite 和导出均默认运行在用户本机；
- 默认不启用云存储、遥测、远程日志、外部 AI 或第三方数据接口；
- 浏览器只连接本机 API；
- 用户数据、数据库、上传、日志和导出不进入 Git；
- 提供本地开发和 Docker Compose 两种启动路径，但两者都不表示外部部署；
- 提供数据集及派生数据的本地清理能力。

## 理由

- 降低隐私和网络依赖；
- 适合课堂、个人电脑和中小商家；
- 用户能够控制数据生命周期；
- 开源示例无需真实数据。

## 后果

- 不提供跨设备同步和多人协作；
- 用户电脑承担计算和存储；
- 需要处理 Windows 路径、中文文件名、端口和本地防火墙；
- 备份责任需在界面和文档中说明。

## 替代方案

- SaaS：易于更新，但引入账户、托管、合规和计费范围；
- 桌面原生封装：可能改善体验，但首版增加打包和更新成本；
- 纯浏览器计算：无法稳定覆盖大文件、DuckDB/SQLite 和报告需求。

## 复审条件

- 用户明确需要受控团队协作；
- 本地 API 安装成为主要采用障碍；
- 有独立隐私评估和资源支持新的部署模式。

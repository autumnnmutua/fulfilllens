# ADR-0010：可审计的本地报告导出与 PDF 准入条件

- 状态：Accepted
- 日期：2026-08-01

## 背景

报告需要在离线环境中打开、共享和复核，同时承载中文、图表、长表、诊断证据和敏感标识控制。直接在前端拼装数字会造成指标漂移；依赖远程图表或字体会破坏本地优先和隐私边界；未经容器验证的 PDF 容易缺字、分页错误或跨平台不一致。

## 决定

1. 后端建立版本化 `ReportDocument`，复用仪表盘筛选、指标、诊断和模拟服务；前端只选择范围与展示预览。
2. Markdown 与自包含 HTML 作为主要报告格式，HTML 只使用内联 CSS/SVG 和系统中文字体栈。
3. CSV 使用独立稳定列契约、UTF-8 BOM 和公式注入转义。
4. 标识默认掩码；包含订单/事件标识必须由前端和 API 双重确认。
5. 大导出使用可查询进度、可取消的本机异步任务；MVP 不把导出文件持久化到数据库。
6. PDF 只有在 Docker 中锁定可再分发中文字体与渲染器，并通过中文、图表和长表分页测试后才能启用。

## 理由

- 单一报告模型使页面、文件和 API 可以对账；
- HTML/Markdown 无需新增重量级浏览器或排版依赖；
- 离线资源避免向第三方泄露打开报告的时间和地址；
- 明确 PDF 准入门槛比提供不可复现的“看似完成”功能更可靠；
- 短生命周期内存任务满足本地 MVP，又避免把包含标识的文件意外留在磁盘。

## 后果

正面：报告可追溯、可测试、离线可读，安全策略统一。负面：API 重启后任务消失；不同系统字体字形略有差异；用户暂时需要使用 HTML 的浏览器打印完成临时 PDF。

## 替代方案

- 前端截图或直接打印：拒绝，难以对账、取消和测试长表；
- 服务端 Headless Chromium：暂缓，当前没有 Docker 环境验证字体、镜像体积和安全更新；
- 云端报告服务：拒绝作为 MVP 默认路径，会改变本地优先与数据出境边界。

## 复审条件

- 阶段 10 获得 Docker 环境并完成多页中文 PDF、字体许可证、内存和启动时延测试；
- 需要跨进程任务恢复或长期本地归档；
- Cloudflare 云模式确定独立的队列、对象存储和数据保留契约。

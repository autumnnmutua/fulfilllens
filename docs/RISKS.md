# FulfillLens CN 风险登记

## 使用方式

- 严重度分为：阻断、高、中、低；
- 每个阶段开始前复查相关风险，成果报告中记录状态变化和新增风险；
- 风险关闭必须有文档、测试、运行结果或人工验收证据，不能只凭口头判断；
- 当前责任角色表示首要推动者，不代表其他角色无需参与。

## 可选 Workers AI 连接

- R-015：真实 API Token 可能因聊天、终端历史或误提交泄露；仓库只提供空占位配置，
  Pydantic 使用 `SecretStr` 脱敏，状态/API/错误不返回 Token。任何已出现在非密钥管理位置的
  Token 都必须轮换；
- R-016：外部模型调用可能产生费用、限流和供应商可用性风险；默认关闭，固定 20 秒超时，
  429 与上游错误使用稳定错误码，探针返回实际 token 用量；
- R-017：本地页面可能被第三方网页尝试触发外部调用；探针使用 POST、显式开关、
  `X-FulfillLens-External-Call: confirm` 自定义头和严格 CORS，且没有自由提示词请求体；
- R-018：物流数据外传和不可解释结论风险；当前客户端只允许固定合成短句，完全不读取导入
  数据，也不接入指标、异常诊断或模拟。未来扩展必须单独评审，不能把模型输出冒充事实。

- R-001/R-014/R-023：报告、预览和 CSV 复用同一个服务端筛选订单集合，头部固定指标、规则、模拟、报告和渲染版本；指标表保留分子、分母、覆盖率与不可计算数；

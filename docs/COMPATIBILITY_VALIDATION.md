## 3. 不修改业务事实的证据

- 自动层只给出数据类型和字段候选，不静默改变用户选择；
- 每个字段建议返回源字段、目标字段、匹配方法、置信度和候选列表；
- 空数量不补为 0，非法时间不自动顺延，附加字段不为通过校验而删除；
- CSV 引号内换行由标准解析器保留；XLSX 公式不执行，错误值和无法转换值进入质量报告；
- Excel 显示格式为连续零的整数按显示值保留前导零；普通业务数量仍按数值校验；
- 未知状态保留原始值并标准化为 `unmapped`，不会伪造已签收状态。

## 4. 自动化证据

本地兼容性测试覆盖目录摘要/下载、CSV 和 XLSX 真实 multipart 上传、解析、映射、Schema 校验、确认导入与指标对账。浏览器测试覆盖 UTF-8/BOM/GBK/GB18030、引号/换行/逗号、多工作表、Excel 日期、前导零、自动类型、值画像、关系推断、批量推荐、单个/批量忽略及撤销、必填防绕过、未知状态、文件类型/大小，并断言合法自主文件不调用网络上传接口。真实 Chrome E2E 在 360/390/430/1366/1440/1920px 完成非标准轨迹 CSV 和多工作表 XLSX，再进入浏览器本地指标、诊断、建议与报告。完整发布命令及最终结果见[最终验收记录](RELEASE_ACCEPTANCE.md)和对应版本[发布说明](releases/v1.1.0.md)。

## 5. 已知边界

- 自动匹配是可解释建议，不保证所有企业自定义字段都能高置信度命中；低置信度或冲突映射必须人工确认；
- 本地 FastAPI 支持安全限制内的用户 CSV/XLSX；Cloudflare 地址在浏览器内处理自主文件及其指标、诊断、建议和报告，确认后的数据不跨浏览器同步，浏览器自有数据尚不支持 What-if；
- `.xls`、`.xlsm`、宏、加密工作簿、外部链接和嵌入对象不在支持范围；
- 无时区日期必须由用户选择默认 IANA 时区，系统不会猜测业务时区。

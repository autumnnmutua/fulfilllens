# 截图与 GIF 拍摄清单

以下截图由 `scripts/capture_release_screenshots.cjs` 从 Cloudflare 模式生产构建自动拍摄，全部使用固定合成数据。2026-08-10 已逐张检查分辨率、关键文案、隐私和文件大小；GIF 仍为可选资产。

## 统一准备

- 只使用仓库固定种子合成案例；不得出现真实姓名、手机号、地址、身份证、运单号或企业名称。
- 浏览器宽度分别验证 1440px 和 360px；主 README 优先使用 1440px，移动端证据可放在文档页。
- 清理浏览器通知、开发工具、账户头像、本机路径和其他窗口。
- 图中数据集名称明确包含“合成案例”；模拟页面必须保留“情景估算”提示。
- 静态图使用 PNG 或优化后的 WebP；GIF 控制时长和体积，并提供等价文字说明。
- 文件名使用英文小写短横线，如 `dashboard-overview.webp`。

## 建议 GIF

1. 从教学案例载入“促销爆单”；
2. 打开总览并筛选承运商；
3. 进入异常诊断查看具体订单证据；

## 验收

- 图像中的关键文案与当前版本一致；
- 360px 页面无横向溢出，桌面表格没有截断关键列；
- 颜色之外还有标签、图例或形状；
- 不展示浏览器保存的密码、Token、下载历史和本机绝对路径；
- 图片压缩后仍可读，单个静态图建议小于 500 KiB，GIF 建议小于 8 MiB；
- README 引用的每个素材文件都真实存在并通过文档链接检查。

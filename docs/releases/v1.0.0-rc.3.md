# FulfillLens CN v1.0.0-rc.3 发布说明

发布日期：2026-08-09

## 新增

- 扩展 CSV/XLSX 字段别名，支持中文、英文、camelCase、snake_case 和常见业务系统名称；
- 增加数据类型候选识别，显示置信度、已命中字段和缺失必填字段，但不静默切换用户选择；
- 映射页显示源字段、目标字段、匹配方法、置信度、未映射附加列和转换说明；
- 增加两份全新合成兼容性样例及导入页入口：非标准订单 CSV、三工作表物流 XLSX；
- 公共 Cloudflare 演示支持对这两份摘要匹配样例进行真实 multipart 上传、转换、校验和确认。

## 修复

- CSV 解析改为保留引号内换行，空白行跳过并给出可见警告；
- XLSX 兼容未缓存工作表维度的生成器，以声明值预检和实际流式计数共同限制行列数；
- Excel 连续零显示格式的整数保留前导零；补充点号日期和中文日期解析；
- Docker API/Web 镜像加入兼容样例资产，避免容器示例目录或下载 404；
- 订单状态补充“妥投”别名，导入后仍保留原始状态和映射证据。

## 测试与验证

- 两份文件均经过文件解析、数据类型识别、自动映射、Schema/质量校验、确认导入和分析对账；
- CSV 8 行有效；XLSX 三张表分别为 6、36、36 行且均无质量错误、重复键或未知状态；
- Worker 回归验证精确样例可上传、未知文件被拒绝，CSV 确认后总览订单数为 8；
- 发布前门禁、Docker smoke、GitHub Actions、Cloudflare 部署和线上验证的最终证据记录于[兼容性验证报告](../COMPATIBILITY_VALIDATION.md)与[最终验收记录](../RELEASE_ACCEPTANCE.md)。

## 已知限制

- 公共 Cloudflare 站点只允许两份公开合成兼容样例；真实业务文件必须使用本地或 Docker 版；
- 自动匹配不能替代业务口径确认，低置信度与冲突字段需要人工选择；
- PDF、Firefox/Safari 和持久云端业务数据仍不属于本 RC 的已验收路径；
- Workers AI 仍只执行显式确认的固定合成连接探针，不读取导入数据，也不参与指标或诊断计算。

## 升级与校验

```powershell
npm.cmd ci
python -m venv apps/api/.venv
.\apps\api\.venv\Scripts\Activate.ps1
python -m pip install -r apps/api/requirements-dev.txt
npm.cmd run release:check
docker compose up --build --detach
```

打开 `/import` 载入两份兼容样例；完成复验后用 `docker compose down --volumes` 清理本次容器数据。最后一个命令会不可恢复地删除 Compose 数据卷。

# FulfillLens v1.0.1 发布说明

发布日期：2026-08-10

v1.0.1 是正式版的新手导入体验更新，不改变 v1.0.0 的数据契约和本地优先边界。

## 主要改进

- 自主上传默认自动判断订单、仓库作业或物流轨迹数据；用户仍可手动指定并获得结构不匹配提示；
- 字段证据组合规范化表头、业务语义、值画像、唯一性/重复规律和当前 Schema；
- HIGH 字段直接应用，MEDIUM 建议一次批量采用，LOW 非必要列一次安全忽略；高级字段表默认折叠；
- 缺少可信事件 ID 时稳定生成；未知状态保留原文并标记 `unmapped`，不因少量未知状态阻断整个文件；
- 日期解析支持中英文月份、AM/PM、显式时区、日优先表达、文件级 DMY/MDY 推断和 date-only 精度；
- 只有物流轨迹时仍提供首末轨迹平均/P50/P90、状态、承运商、异常、时间线、诊断、行动建议和报告；OT/IF/OTIF 保持不可计算并说明所需订单字段。

## 兼容验收

两份一次性用户附件均为 54 行、21 列的非标准物流轨迹 CSV。真实浏览器验收结果：

- 自动识别：两份均为物流轨迹；
- 导入：54/54 行，静默丢行 0；
- 基数：各 10 个运单、10 个业务单、10 个承运商；
- 新手操作：逐字段确认 0；第一份批量确认 0，第二份批量确认 1；
- 质量：非法时间 0、阻断 0；未识别状态作为非阻断覆盖率说明保留；
- 下游：总览、诊断、报告、专业行动方案和管理层简报均完成浏览器路径验收。

这两份附件未提交 GitHub、未进入 Cloudflare 资产，也不是生产、CI 或发布依赖。通用能力由仓库中的完全合成 fixture 持续回归。

## 隐私与分析边界

- Cloudflare 自主文件仅在浏览器内解析和保存；原始内容和标准化行不发送给 Worker 或 Workers AI；
- 指标、诊断与 recommendation facts 由确定性逻辑生成；AI 不可用时双视图建议仍可显示；
- tracking-only 数据不会用承诺日期或件数跨表伪造 OT、IF、OTIF；
- 浏览器自有数据的 What-if、跨设备同步、身份权限和可靠 PDF 仍不在本版本范围。

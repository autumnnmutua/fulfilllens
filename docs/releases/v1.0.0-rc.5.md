# FulfillLens v1.0.0-rc.5 发布说明

- 发布日期：2026-08-09
- 发布类型：预发布版本
- GitHub：<https://github.com/autumnnmutua/fulfilllens>
- Cloudflare：<https://fulfilllens.esthertreu3724.workers.dev>

## 主要变化

- 项目公开品牌从 **FulfillLens CN** 更名为 **FulfillLens**，保留 Git 历史、Release 历史和必要的内部兼容标识；
- 字段映射目标列和下拉菜单获得可读宽度，长中文名称与英文标准字段可同时阅读，移动端改为全宽卡片；
- 每个源字段可明确忽略或取消忽略，界面区分自动映射、人工映射、已忽略和待处理；
- 浏览器与 FastAPI 共用 ignored/unresolved 契约，被忽略列不进入标准数据或后续分析；
- 忽略唯一必填候选仍会触发缺少标准字段，不能绕过 Schema；
- 浏览器导入 E2E 在启动 Worker 前固定执行 Cloudflare 模式构建，避免复用错误构建产物；
- 自主 CSV/XLSX、自动转换、三套教学案例、指标、透明诊断、What-if 和报告能力保持不变。

## 隐私与兼容

Cloudflare 在线版仍在浏览器内完成自主文件的安全检查、解析、映射、标准化和质量校验。原始文件不发送给 Worker；确认后的标准化数据仅保存在当前浏览器 IndexedDB。Workers AI 不读取导入文件或分析数据。

为避免品牌迁移导致现有用户浏览器数据和 Docker 本地卷变成孤儿，内部 IndexedDB 名称和 Compose 项目名暂时保留旧标识。历史 Schema `$id` 也继续作为稳定契约标识；这些内容不再用于公开产品名称。

## 校验方法

发布提交必须同时通过根目录格式、lint、TypeScript/Python 类型检查、前后端/Worker 测试、构建、真实 Chrome 字段映射/CSV/XLSX E2E、Docker smoke、依赖审计和文档/敏感信息扫描。实际命令结果记录在 [最终验收记录](../RELEASE_ACCEPTANCE.md) 和 GitHub Actions。

## 已知限制

- Cloudflare 浏览器自有数据尚未接入 Worker 指标、诊断、模拟和报告，完整自有数据分析仍使用本地/Docker；
- Firefox、Safari 和 PDF 尚未达到本候选版本的正式发布准入；
- 自动字段建议覆盖常见别名，但不承诺识别任意企业自定义 Excel；低置信度内容必须人工确认。

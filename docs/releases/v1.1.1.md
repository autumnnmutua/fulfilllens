# FulfillLens v1.1.1 发布说明

发布日期：2026-08-11

v1.1.1 是 v1.1.0 之后的数据正确性补丁版本。它不修改 v1.0.0 或 v1.1.0 的标签、Release 与历史，重点修复时长分布、分析实体口径和项目自带文件重新导入的可靠性。

## 主要修复

- 浏览器本地分析现在从与 Mean、P50、P90 完全相同的时长样本生成直方图分箱；有样本时不再出现空白分布图，无样本时显示具体原因。
- tracking-only 分析以运单为实体，显示“轨迹首末时效分布”，并明确它不是完整订单履约时长。
- 总览和报告分别展示原始记录、有效记录、事件、唯一运单、唯一业务订单和当前分析实体，避免把 54 条轨迹误读为 54 个订单。
- tracking-only 的时效、承运商维度、诊断证据与时间线复用同一分析实体标识，避免订单号/运单号同时存在时错位。
- 完整订单的 Mean、P50、P90 与分布图统一排除取消/退回样本；单样本直方图也能返回有效区间。
- 标准节点耗时图小幅增加底部间距，在不改变图表高度的前提下改善图例、数字和坐标轴可读性。

## 导入与回归

- 项目正式提供的 22 张 CSV/XLSX 数据表均经过浏览器导入流水线回归：解析、数据类型识别、字段映射、安全忽略、Schema/质量校验和确认导入全部通过。
- 兼容性订单 CSV 通过真实 Chromium 重新上传后，自动识别为订单数据并直接进入分析；80 条原始/有效记录、80 个唯一业务订单和履约时长分布能够对账。
- 多工作表兼容性 XLSX 能选择物流轨迹工作表并直接进入分析；不依赖文件名白名单。
- 两份一次性 54×21 用户附件再次作为人工兼容验收，均为 54 行、10 个运单、10 个业务订单且零静默丢行。附件未提交仓库，不是生产、CI、Cloudflare 或 Release 依赖。

## 数据与隐私边界

- 用户导入、Demo、兼容样例和教学数据继续使用隔离的分析会话；切换文件必须产生新的输入指纹并重新计算指标、诊断、建议和报告。
- tracking-only 不借用承诺日期或数量伪造 OT、IF、OTIF；缺少订单级字段时这些指标明确为不可计算。
- 自主文件继续只在浏览器内解析与保存，原始内容和标准化行不发送给 Worker 或 Workers AI。

## 已知限制

- Firefox、Safari 和物理移动设备尚未进入正式验收；Chrome/Chromium 是当前正式浏览器系列。
- PDF 中文字体、分页和长表尚未达到可靠导出门槛；Markdown、自包含 HTML 和安全 CSV 是正式路径。
- Cloudflare 浏览器自主数据暂不支持 What-if 或跨设备同步。
- 自动映射无法覆盖所有企业私有字段；会改变业务含义的关键歧义仍需要一次确认。

# FulfillLens v1.0.0 发布说明

发布日期：2026-08-10

FulfillLens v1.0.0 是首个正式版本：面向物流教学、教师和中小电商商家，提供本地优先、可解释、可复算的履约分析工作流。

## 主要能力

- 本地或浏览器内导入 CSV/XLSX，支持 UTF-8/BOM、GBK/GB18030、多个工作表、Excel 日期、文本数字和前导零标识；
- 规范化表头、共享业务别名、有限值画像和人工复核结合的字段映射；
- 一键应用高置信度推荐映射，以及可撤销的“一键忽略可忽略项”；必填和关键候选不会被批量忽略；
- `mapped/generated/inferred/ignored/unresolved/blocking` 六种可解释状态，稳定事件 ID 派生和未知状态 `unmapped` 保留；
- OT、IF、OTIF、P50、P90、节点耗时、异常率、取消率和覆盖率，缺少订单字段时明确不可计算；
- 八类透明异常诊断、订单/运单证据时间线、确定性 What-if 情景估算和安全报告导出；
- 基于同一 recommendation facts 的“专业行动方案”和“管理层简报”，包含优先级、数据证据、建议 KPI、风险及下一步验证；
- 三套固定种子、完全合成的教学案例；
- Cloudflare 正式在线版。自主文件在浏览器内解析、校验、分析和生成建议，原始文件与标准化行不上传到 Worker。

## 正式版修复

- 已忽略源列不再继续产生逐行必填错误或占用未处理数量；真正缺失的标准必填字段仍是阻断项；
- 质量问题改为“问题、原因、影响、建议操作”，并在存在可信候选时给出可执行的推荐映射；
- 缺少可信 `tracking_event_id` 时按标准语义字段和源行号生成稳定、唯一、可复现的 ID；
- 现实日期格式、混合中英文物流状态、旧系统码和异常标记由确定性规则处理，原始值始终保留；
- 修复浏览器本地轨迹数据进入分析时的派生数据集读取错误；
- 浏览器本地报告按 CSV 用途输出正确结构，订单导出不再依赖远程用户数据 API；
- 专业/管理两个建议视图共享事实 ID 和数字，AI 不可用时仍由模板输出。

## 隐私边界

- Cloudflare 自主文件路径不调用原始上传 API；确认后的标准数据仅保存在当前浏览器 IndexedDB，可在设置页删除；
- 行动建议只消费确定性指标与诊断事实，不默认把原始 CSV 或标准化行发送给 Workers AI；
- Workers AI 不是核心分析单点故障，不计算 KPI、规则或优先级；
- 仓库中的样例和截图只使用完全合成数据；一次性的 54×21 用户测试附件不是生产、CI、部署或发布依赖。

## 已知限制

- 浏览器自主数据暂不支持 What-if；本地/Docker 版支持完整方案流程；
- 浏览器 IndexedDB 不跨设备同步，也不提供多用户身份、权限或云端长期存储；
- Firefox、Safari 和物理移动设备尚未进入正式验收；
- PDF 中文字体、分页和长表尚未达到可靠导出门槛，Markdown、自包含 HTML 和安全 CSV 是正式路径；
- 自动映射不能保证识别所有企业自定义字段，低置信度或冲突候选必须人工确认。

## 运行与校验

```powershell
npm ci
python -m venv apps/api/.venv
.\apps\api\.venv\Scripts\Activate.ps1
python -m pip install -r apps/api/requirements-dev.txt
npm run release:check
npm run dev
```

Docker：

```powershell
docker compose up --build -d
docker compose ps
docker compose down
```

# FulfillLens CN v1.0.0-rc.4 发布说明

发布日期：2026-08-09

## 本次完成

- Cloudflare 在线版允许用户自主选择任意合法文件名的 `.csv` / `.xlsx`，不再限于仓库公开合成样例；
- “选择数据类型”操作区新增“自主上传文件”，直接进入既有第 2 步并打开系统文件选择器；
- 浏览器本地完成扩展名/MIME/签名检查、CSV/XLSX 解析、数据类型识别、字段建议、时间/数字/状态标准化、Schema 和质量校验；
- 自动字段建议支持中文、英文、大小写、camelCase、snake_case、空格、下划线、连字符及共享业务别名，显示方法、置信度和人工确认要求；
- 未知物流状态保留原值并标记 `unmapped`；标识优先按字符串处理，Excel 连续零格式保留前导零；
- 确认后的标准化数据只保存在当前浏览器 IndexedDB，设置页可删除；原始文件不发送给 Cloudflare，确认/取消后释放引用；
- 原有正常运营、促销爆单、承运商异常和两份兼容性样例均保留。

## 根因与修复

旧 Cloudflare Worker 在 `/api/imports/upload` 对文件计算 SHA-256，只允许两份公开兼容样例摘要；解析/质量结果是固定合成契约，因此未知自主文件会被合成样例限制错误拦截。rc.4 没有只删除判断，而是让 Cloudflare 构建改用浏览器本地导入服务；Worker 原始上传路由返回 `BROWSER_LOCAL_IMPORT_REQUIRED`，防止旧客户端误传。

导入任务状态同时改为单一最新校验来源：映射变化后任务回到待映射，旧质量报告失效，只有最新 Schema 与质量校验通过后才允许确认。

## 验证

- 前端：36 项单元/组件测试；
- Worker：14 项契约测试；
- Python API 与跨层契约：227 项测试；
- Chrome E2E：360/390/430px 布局，非标准 12 行轨迹 CSV、多工作表 XLSX、刷新持久化、PDF 拒绝，并断言原始上传请求为 0；
- 生产构建、lint、format check、TypeScript/mypy、依赖/许可证、安全扫描、Docker 与线上验收结果见[最终验收记录](../RELEASE_ACCEPTANCE.md)。

## 隐私边界

Cloudflare 自主文件的原始内容不会上传或保存到 Worker、R2、D1 或第三方服务。公开合成案例仍通过 Worker API 分析。Workers AI 绑定只用于固定合成连通探针，不读取导入数据。

## 已知限制

- 浏览器自主确认的数据集尚未接入 Worker 指标、诊断、模拟和报告；完整业务数据分析仍使用本地/Docker；
- 浏览器数据不跨设备同步，清理浏览器站点数据也会删除它；
- 不支持 `.xls`、`.xlsm`、加密工作簿、宏、公式计算、外部链接或任意 Excel 结构；
- Firefox/Safari 和 PDF 仍未纳入本轮发布验收；
- Ant Design/ECharts 生产块仍较大，后续可继续做首屏拆分。

## 运行与回滚

```powershell
npm.cmd ci
npm.cmd run build:cloudflare
npm.cmd run test:browser-import:local
npm.cmd run deploy:cloudflare
```

回滚时使用 GitHub 前一发布标签或 Cloudflare Worker 部署历史；回滚后重新检查 `/health`、`/api/version`、合成案例和浏览器导入隐私边界。

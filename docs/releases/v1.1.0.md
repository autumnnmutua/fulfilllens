# FulfillLens v1.1.0 发布说明

发布日期：2026-08-11

v1.1.0 是 v1.0.0 之后的数据正确性与新手导入更新。它不会改写 v1.0.0 标签、Release 或历史，重点修复数据上下文污染，并让非标准 CSV/XLSX 在不伪造指标的前提下更快进入分析。

## 主要改进

- “一键整理并分析”在一次操作内应用高置信映射、生成安全内部 ID、忽略非分析列、重新校验并创建独立分析会话；
- 自动类型与字段判断综合 Unicode 规范化、中文/英文业务语义、值画像、日期成功率、ID 重复规律、列间关系和用户选择的数据类型；
- 每次用户导入都会清除旧 Demo/兼容样例选择并生成 `analysis_fingerprint`；总览、诊断、建议和报告共享同一个当前上下文；
- 物流轨迹只需运单、时间与原始状态即可进入能力驱动分析。缺少订单承诺/数量时 OT、IF、OTIF 显示不可计算，而非错误的 0%；
- 分析页新增当前可分析能力、数据来源、样本量、关联率、时间范围、口径版本和输入指纹；
- 兼容性订单 CSV 扩充至 80 行，兼容性 XLSX 三张表扩充至 80/480/480 行；数据保持固定生成、可复现且完全合成。

## 正确性修复

- 修复自主轨迹导入可能与旧兼容样例订单一起分析，导致不同 CSV 呈现相同或高度相似指标的问题；
- 修复页面切换后仍读取旧 `localStorage`/IndexedDB 选择的问题；
- 修复取消和退回轨迹被排除在首末时效样本外、未知状态被直接计作经营异常的问题；
- 支持没有 `order_id`、`carrier_id` 或 `location` 的部分轨迹数据；无关字段缺失只关闭对应能力；
- 主动组合订单与事件且关联率为 0 时拒绝静默混合，并显示关联修复建议。

## 人工兼容验收

两份一次性用户附件均为 54 行、21 列、10 个运单/业务单/承运商的非标准物流轨迹 CSV。真实浏览器路径均实现 54/54 行导入、零静默丢行、零阻断、零逐字段确认，且原始文件上传请求为 0。

- CSV #1：2026-07-01 至 2026-07-09，首末轨迹 Mean/P50/P90 为 33.64/29.83/58.99 小时；
- CSV #2：2026-08-12 至 2026-08-22，首末轨迹 Mean/P50/P90 为 30.78/31.78/34.04 小时；
- 两次导入产生不同指纹、时间范围、指标、诊断和建议。

这两份附件未提交 GitHub、未进入 Cloudflare 资产，也不是生产、CI 或发布依赖。通用能力由仓库内完全合成的最小 fixture 和扩展兼容样例持续回归。

## 隐私与边界

- Cloudflare 自主文件仅在浏览器内解析和保存；原始内容与标准化行不发送给 Worker 或 Workers AI；
- 指标、诊断与 recommendation facts 由确定性逻辑生成；AI 不可用时双视图建议仍可显示；
- tracking-only 不会借用“预计送达日”或“件数”跨表伪造 OT/IF/OTIF；
- 浏览器自有数据的 What-if、跨设备同步、身份权限和可靠 PDF 仍不在本版本范围。

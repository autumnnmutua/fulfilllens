# FulfillLens v1.1.2

发布日期：2026-08-13

## 本次更新

- 完整移除 Cloudflare Worker 外部生成式推理 binding、状态接口和固定合成探针；
- 移除 FastAPI 外部推理客户端、配置、环境变量、路由与响应模型；
- 移除 Web 设置页的外部推理卡片、确认框、探针按钮、客户端和类型；
- 设置页保留并强化本地数据查看、删除和错误反馈；
- 旧集成路径统一返回标准 404，防止遗留客户端误认为功能仍可用；
- 更新中英文 README、部署、架构、安全、FAQ、导入和风险文档。

## 不变的核心能力

CSV/XLSX 浏览器本地导入、自动字段映射、状态标准化、质量校验、指标、透明诊断、专业行动方案、管理层简报、What-if、合成案例与报告继续由确定性代码提供。移除外部推理不会减少这些能力，也不会改变指标公式、规则阈值或数据契约。

## 隐私与部署边界

- 在线自主文件仍只在浏览器内解析和保存；原始文件与标准化行不发送给 Worker 或第三方服务；
- Cloudflare Worker 只托管 SPA 与公开合成案例 API；
- 运行时不需要模型 Account ID、Token、模型名称或推理 binding；
- Wrangler OAuth 或 CI 发布凭据只用于部署，不进入应用运行时或浏览器。

## 升级方式

```powershell
git pull --ff-only
npm.cmd ci
python -m pip install -r apps/api/requirements-dev.txt
npm.cmd run release:check
```

Cloudflare 维护者可在质量门槛通过后执行：

```powershell
npm.cmd run build:cloudflare
npm.cmd run test:cloudflare
npm.cmd run deploy:cloudflare
```

## 已知限制

- 浏览器自主数据暂不支持 What-if 或跨设备同步；
- PDF 尚未达到可靠中文字体、分页和长表发布门槛；
- 自动映射不能保证覆盖所有企业私有字段，关键歧义仍可能需要一次确认；
- Firefox、Safari 和物理移动设备尚未完成正式验收。

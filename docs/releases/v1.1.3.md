# FulfillLens v1.1.3

发布日期：2026-08-17

## 本次更新

- 在解析带 `Z` 或 `+08:00` 等显式时区的 ISO 时间前校验真实日历日期，拒绝 2 月 30 日、4 月 31 日等不可能日期；
- 严格校验浏览器分析会话元数据，损坏的旧缓存不会再因错误的数据集编号类型使分析页崩溃；
- 保持现有存储键、IndexedDB 数据、API 契约、指标定义、诊断规则和用户导入流程不变。

## 数据正确性

非法日期不再被运行时静默改写后参与 Mean、P50、P90 或节点耗时。金标准继续验证 OT 4/5、IF 5/6、OTIF 3/5，以及 Mean/P50/P90 52/52/63 小时；缺少必要字段时仍返回不可计算，而不是 0。

## 升级方式

```powershell
git pull --ff-only
npm.cmd ci
python -m pip install -r apps/api/requirements-dev.txt
npm.cmd run release:check
```

## 已知限制

- 浏览器自主数据暂不支持 What-if 或跨设备同步；
- PDF 尚未达到可靠中文字体、分页和长表发布门槛；
- 自动映射不能保证覆盖所有企业私有字段，关键歧义仍可能需要一次确认；
- Firefox、Safari 和物理移动设备尚未完成正式验收。

# FulfillLens CN v1.0.0-rc.2 发布说明

> 发布类型：候选版本。该版本已通过阶段 12 本机全量验收；最终发布证据以标签提交上的 GitHub Actions 结果为准。

## 在线地址

- Cloudflare 在线演示：<https://fulfilllens-cn.esthertreu3724.workers.dev>
- 完整分析能力：本地开发或 Docker Compose

在线版提供公开确定性合成案例、同源指标/诊断/订单级 What-if/报告接口和 Cloudflare 原生 Workers AI 合成探针，不接收或保存真实订单及个人信息。真实文件、DuckDB/SQLite 完整分析和持久方案仍使用本地或 Docker。

## 本候选版本修复

- 修复生产分块把 Ant Design 拆成循环依赖小块而导致真实浏览器白屏的问题；
- 修复设置页无数据空状态文字对比度不足；
- API Docker 镜像纳入三套完全合成的教学案例和透明诊断规则，恢复容器内一键载入与诊断；
- 案例载入改为先校验资产，并在中途注册失败时回滚本次数据集；
- Docker smoke 新增真实 Chrome、三种视口与 axe/WCAG 审计，防止只检查 HTTP 200 而漏掉前端运行时错误；
- 修复在线演示 P50/P90 口径和直接调整汇总指标的问题，改为 Type-7 与订单/节点副本变换后统一复算；
- 修复在线报告跨 Worker 实例后丢失筛选，以及合成节点时间线与订单生命周期不一致的问题；
- 在 Windows 重启后完成 Docker Desktop、Compose 构建、启动、健康、案例载入和数据清理复验。

## 已知限制

- Cloudflare 地址只处理公开合成数据，不是 FastAPI/DuckDB/SQLite 完整云迁移，也不提供真实文件上传或持久业务方案；
- Workers AI 只执行用户确认后的固定合成连通性探针，不参与指标、诊断、模拟，也不会自动操作网页；
- PDF 未开放；可靠报告主路径为 Markdown 与自包含 HTML；
- 本轮实际浏览器验收为 Chrome/Chromium，Firefox 和 Safari 未验证；
- 5 万订单基准峰值内存约 1.35 GiB，不适合直接搬入内存受限的 Worker；
- 前端 Ant Design 生产块压缩前约 1.18 MB、gzip 约 371 KB，功能正确但仍有首屏性能优化空间；
- RC 期间本地数据库结构仍可能调整，不承诺直接跨版本复用 DuckDB/SQLite 文件。

## 升级与回滚

升级前先导出需要保留的报告并备份被忽略的 `data/local/`。若需回滚，切换到上一标签、重新安装锁定依赖并重建容器；不要把旧数据库文件当作稳定跨版本接口。线上预览可通过 Cloudflare Workers 版本历史回滚，回滚不改变本地数据。

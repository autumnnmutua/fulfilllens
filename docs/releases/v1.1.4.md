# FulfillLens v1.1.4

发布日期：2026-08-26

生产入口：<https://fulfilllens.esthertreu3724.workers.dev>

## 本次修复

- 严格校验 ISO 8601 与旧式 GMT 时间中的显式时区偏移，拒绝小时超过 14、分钟超过 59，以及 `+14:00` 之外的 14 时偏移，避免 JavaScript 自动归一化非法时间后污染 Mean、P50、P90 或节点耗时。
- 浏览器数据集写入和删除现在等待 IndexedDB 事务完整提交后才同步内存状态；请求成功但事务随后中止时不再向页面报告假成功。
- IndexedDB 请求、事务创建、事务错误和事务中止均统一关闭数据库连接并保留可读错误，失败数据不会残留在内存缓存中。

## 兼容性与隐私

- 不改变 API、Schema、字段映射、指标、诊断、建议、What-if、报告或 Cloudflare 路由。
- 继续保留既有 `fulfilllens-cn-browser-data` 浏览器数据库名称、`datasets` 对象仓库和数据集结构，避免使旧版本本地数据失联。
- 自主 CSV/XLSX 仍只在浏览器内解析、校验和分析；原始文件与标准化行不会发送到 Worker 或第三方服务。
- `v1.0.0` 至 `v1.1.3` 的 tag、Release 与历史提交均保持不变。

## 已知限制

- Firefox、Safari 与物理移动设备尚未纳入正式浏览器矩阵。
- PDF 仍未达到可靠中文字体、分页和长表导出门槛；Markdown、自包含 HTML 与安全 CSV 是正式路径。
- Cloudflare 浏览器自主数据暂不支持 What-if 方案管理或跨设备同步。
- 自动映射不会强猜会改变业务含义的低置信度字段；此类歧义仍需一次人工确认。

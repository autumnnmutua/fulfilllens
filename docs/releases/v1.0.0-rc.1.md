# FulfillLens CN v1.0.0-rc.1 发布说明（草案）

> 状态：发布候选资料已准备，Cloudflare 受限在线预览已部署；尚未创建 GitHub 远程、标签或 Release。只有阶段 12 发布验收通过后才应发布正式版本。

## 已完成

- CSV/XLSX 导入、工作表与编码处理、字段映射、质量校验和状态标准化；
- OT/IF/OTIF、时效、节点、异常、取消、退回和覆盖率的可复算指标；
- 趋势、分布、瓶颈、维度对比、订单明细与证据追溯；
- 八类透明异常规则，区分事实、规则判断、可能原因与建议核查；
- 仓内、揽收、承运商结构和承诺时效的订单/事件层 What-if 模拟；
- 正常运营、促销爆单、承运商异常三套固定种子教学案例；
- Markdown、自包含 HTML 与五类安全 CSV 导出；
- 本地数据清理、敏感字段默认排除、公式注入与文件安全保护；
- 中文默认界面、中英文文档、移动端和 Chromium 可访问性基线。

## 已知限制

- Docker Desktop 与 Compose 已安装，WSL/虚拟机平台功能已启用但等待 Windows 重启生效；本机 Compose smoke 尚未执行，GitHub Actions 也需在首次推送后实跑。
- Firefox 与 Safari 尚未验证；当前实际浏览器证据为 Chromium。
- PDF 未开放，可靠主路径是 Markdown 和自包含 HTML。
- 5 万订单基准峰值内存约 1.35 GiB，不适合直接运行在 Cloudflare Worker 的受限内存中。
- Cloudflare 在线预览已提供静态页面、健康/版本接口和 Workers AI 原生绑定探针；FastAPI、DuckDB、SQLite、本地临时文件和进程内任务仍不能零修改迁移。
- 诊断不证明经营因果；模拟是情景估算，不是预测或服务保证。
- Workers AI 默认关闭，不计算指标、不替代规则，也不会自动完成网页操作。

## 从旧开发快照升级

该版本是首个准备公开的发布候选，没有稳定版数据迁移承诺。升级前：

1. 导出需要保留的 Markdown/HTML/CSV 报告；
2. 停止 Web 与 API；
3. 备份已忽略的 `data/local/`，不要提交备份；
4. 更新源码后重新运行 `npm ci` 和 Python 依赖安装；
5. 先用合成案例验收，再决定是否继续使用旧本地数据。

本地数据库 Schema 在 RC 期间仍可能变化。不建议把旧 `analytics.duckdb` 或 `control.sqlite3` 当作跨版本稳定接口。

## 运行方式

```powershell
npm ci
python -m venv apps/api/.venv
.\apps\api\.venv\Scripts\Activate.ps1
python -m pip install -r apps/api/requirements-dev.txt
npm run dev
```

打开 <http://127.0.0.1:5173/cases>，载入一个合成案例。

Docker 候选路径：

```powershell
docker compose up --build -d
docker compose ps
```

## 校验

```powershell
npm run release:check
python scripts/performance_benchmark.py
python scripts/smoke.py
docker compose config --quiet
```

随后人工检查导入、总览筛选、异常时间线、三个模拟方案、报告导出和设置页数据清理。Docker 不可用时必须将相关检查标记为未执行，不能推断通过。

# 跨模块测试目录

此目录用于跨文档数据契约测试，并预留跨应用集成测试、端到端测试、性能基准和发布验收测试。

模块级单元测试可与对应源码共置。任何测试失败都应定位并修复根因，不得通过跳过测试、降低断言或静态假数据伪造通过。

## 当前验证范围

激活 `apps/api/.venv` 后，在仓库根目录执行全部测试：

```powershell
npm run test
```

也可仅执行 Python 契约和 API 测试：

```powershell
python -m pytest apps/api/tests tests
```

跨模块测试覆盖：

- JSON Schema 本身符合 Draft 2020-12；
- 三类合成行记录通过；
- 必填字段缺失、数量类型错误、无时区时间、未知状态和额外字段失败；
- `unmapped` 状态保留非空原始值；
- CSV 模板仅含表头，且字段顺序与 Schema 一致；
- 数据字典、指标依赖、标准状态、ADR 索引与机器契约一致；
- 诊断、模拟、合成案例和报告契约；
- CSV/XLSX 导入到分析、诊断、模拟、报告和数据清理的三条端到端流程；
- 发布文档本地链接、依赖许可证和隐私扫描由根目录 `npm run release:check` 补充验证。

API 模块测试还覆盖健康/版本、标准错误、CORS、安全响应头和 OpenAPI；前端测试位于 `apps/web/src/`。
